# Documento de instrucciones Antigravity 2.0

Este documento consolida las instrucciones para el agente de UI/UX y desarrollo frontend, tomando en cuenta el backend construido en Spring Boot y la estructura inicial del frontend.

---

## 1️⃣ Gestión de Imágenes y Archivos

### Objetivo
Implementar soporte completo para carga, visualización, actualización y eliminación de imágenes asociadas a entidades del sistema.

Entidades que soportan imágenes:

- `ConfiguracionEmpresa.logo_url`
- `Producto.imagen_url`
- `Categoria.imagen_url`
- `Empleado.avatar_url`

---

### Nuevo módulo frontend

Crear un módulo compartido:

```text
src/
├── shared/
│   ├── components/
│   │   ├── ImageUploader.tsx
│   │   ├── ImagePreview.tsx
│   │   ├── DragDropUploader.tsx
│   │   └── AvatarUploader.tsx
│   │
│   └── services/
│       └── uploadApi.ts
Experiencia UX requerida

El usuario debe poder:

Seleccionar imagen desde dispositivo
Arrastrar y soltar imagen
Ver previsualización inmediata
Reemplazar imagen existente
Eliminar imagen antes de guardar
Visualizar progreso de carga
Restricciones
Formatos permitidos: JPG, JPEG, PNG, WEBP
Tamaño máximo recomendado: 5 MB
Mostrar mensaje de error si: formato inválido, tamaño excedido, error de conexión
Integración por módulo

Productos:
Formulario ProductoPage → producto.imagen_url

Categorías:
Formulario CategoriaPage → categoria.imagen_url

Empleados:
Formulario EmpleadoPage → empleado.avatar_url

Configuración Empresa:
Formulario ConfiguracionEmpresaPage → configuracion_empresa.logo_url

API esperada
POST /api/uploads
PUT /api/uploads/{id}
DELETE /api/uploads/{id}
GET /api/uploads/{filename}

Arquitectura desacoplada para:

almacenamiento local
servidor
S3
Cloudinary
Componentes reutilizables obligatorios
ImageUploader: Upload simple
AvatarUploader: Upload circular para usuarios
ImagePreview: Vista previa responsiva
GalleryModal: Visualización ampliada
Dashboard

Mostrar imágenes de:

Productos más vendidos
Categorías destacadas
Logo de empresa
Diseño visual
Skeleton loaders durante carga
Indicador de progreso
Placeholder cuando no exista imagen
Compresión automática antes del envío si es posible
2️⃣ Módulos backend recomendados

Para gestionar realmente las imágenes, se recomienda agregar:

controller/
    UploadController.java

service/
    UploadService.java

dto/
    UploadResponse.java

config/
    FileStorageConfig.java

Actualmente tu BD almacena URLs, pero no hay lógica de subida ni almacenamiento real.
